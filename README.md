# رزومه آنلاین ستاره میرزائی

وب‌سایت رزومه‌ی ایستا با HTML، CSS و JavaScript؛ بدون فریم‌ورک یا وابستگی build. بخش پروژه‌ها در مرورگر، مخازن عمومی GitHub را از API رسمی دریافت می‌کند.

## فایل‌ها

```text
MyResume/
├── index.html
├── style.css
├── script.js
├── favicon.svg
└── README.md
```

## اجرای محلی

می‌توانید `index.html` را مستقیماً باز کنید. برای اطمینان از دریافت پروژه‌های GitHub، آن را با یک وب‌سرور محلی اجرا کنید؛ برای نمونه در VS Code افزونه Live Server را اجرا کنید یا در Python دستور زیر را از پوشه پروژه اجرا کنید:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000` را در مرورگر باز کنید. دریافت پروژه‌ها به اینترنت نیاز دارد. اگر API در دسترس نبود، آرایه‌ی `editableProjects` در `script.js` برای درج اطلاعات واقعی به‌صورت دستی آماده است.

## انتشار در GitHub Pages

1. در GitHub یک repository عمومی با نام دقیق `strhmirzaei-ux.github.io` بسازید.
2. فایل‌های این پوشه را در ریشه‌ی repository قرار دهید و push کنید.
3. در repository وارد **Settings → Pages** شوید.
4. در بخش **Build and deployment**، گزینه‌ی **Deploy from a branch** و سپس شاخه‌ی `main` و پوشه‌ی `/(root)` را انتخاب و ذخیره کنید.
5. پس از پایان انتشار، صفحه در نشانی `https://strhmirzaei-ux.github.io` در دسترس خواهد بود.

## ویرایش محتوا

- اطلاعات شخصی و بخش‌های رزومه در `index.html` هستند.
- رنگ‌ها، چیدمان و breakpoint واکنش‌گرا در `style.css` هستند.
- رفتار منو، حالت تیره و دریافت/مرتب‌سازی پروژه‌ها در `script.js` هستند.
- پروژه‌ها از مخازن عمومی حساب معرفی‌شده خوانده می‌شوند؛ فهرست جایگزین قابل ویرایش در `editableProjects` قرار دارد.

لینک LinkedIn یا فایل PDF در اطلاعات موجود ارائه نشده بود، بنابراین به صفحه افزوده نشده است. زمان کارآموزی و جزئیات دستاوردها نیز در اطلاعات ورودی مشخص نبود و عمداً بازه یا دستاوردی ساخته نشده است.
